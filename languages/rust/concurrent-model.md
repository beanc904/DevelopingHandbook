# 所有权/共享模型

| 类型           | 是否堆分配 | 是否可共享所有权 | 是否线程安全       | 是否支持可变性     | 典型用途              | 本质机制       |
| ------------ | ----- | -------- | ------------ | ----------- | ----------------- | ---------- |
| `Box<T>`     | 是     | 否（独占）    | 取决于 T        | 正常 Rust 规则  | 递归类型、trait object | 堆分配 + 独占拥有 |
| `Rc<T>`      | 是     | 是（引用计数）  | 否            | 不可变共享       | 单线程图结构、UI 树       | 非原子引用计数    |
| `Arc<T>`     | 是     | 是（引用计数）  | 是            | 不可变共享       | 多线程共享数据           | 原子引用计数     |
| `Weak<T>`    | 是     | 弱引用      | Rc/Arc 取决于来源 | 否           | 解决循环引用            | 不增加强引用计数   |
| `Cell<T>`    | 否     | 否        | 否            | 可变（Copy 类型） | 小数据内部可变           | 编译期借用绕过    |
| `RefCell<T>` | 否     | 否        | 否            | 可变（运行期检查）   | 单线程内部可变           | 运行期借用检查    |

# 并发/访问控制模型

| 类型                       | 是否阻塞线程       | 是否可多读 | 是否可多写 | 是否 async 友好 | 典型组合                   | 本质机制       |
| ------------------------ | ------------ | ----- | ----- | ----------- | ---------------------- | ---------- |
| `std::sync::Mutex<T>`    | 是            | 否     | 否     | 不推荐         | `Arc<Mutex<T>>`        | OS / 线程阻塞锁 |
| `std::sync::RwLock<T>`   | 是            | 是     | 否     | 不推荐         | `Arc<RwLock<T>>`       | 读写锁        |
| `tokio::sync::Mutex<T>`  | 否（挂起 future） | 否     | 否     | 是           | `Arc<tokio::Mutex<T>>` | async 调度锁  |
| `tokio::sync::RwLock<T>` | 否            | 是     | 否     | 是           | async 共享读多写少           | async 读写锁  |
| `Atomic*` 类型             | 否            | N/A   | 单变量   | 是           | `Arc<AtomicUsize>`     | CPU 原子指令   |
